# Furnishing symbol library (CC0)

Top-view architectural symbols used by the Furnishings palette.

* Every SVG `viewBox` is in **inches** (`0 0 WIDTH DEPTH`), so the app
  renders each symbol at true scale (1 scene unit = 1").
* `manifest.json` lists the catalog: `id`, `name`, `category`, `file`,
  `width_in`, `depth_in`, `price` (USD purchase cost; the app's
  AI ‣ Update furnishing prices… tool fills these in), plus the four
  fields the 3D viewers read:
  * `height_in` — the item's height in inches.  **Required, and it has
    no default**: a wrong height supplied by a default cannot be told
    apart from a right one, so a symbol added without one stops the
    generator instead.  These are authored architect's nominals.
  * `elevation_in` — the height of the item's underside above the
    level's floor.  `0` for anything floor-bearing; non-zero for the
    wall-hung items (upper cabinets, the large TV, the electric panel,
    the car charger, the battery wall) and for the counter-mounted
    `kitchen_sink`, whose rim then lands at the standard 36".
  * `form` — which solid generator builds it: `box`, `slab` (a top on
    legs), `seat`, `bed`, `basin`, `enclosure`, `vehicle`, and the
    reserved `planting` and `prism`.  A viewer that does not implement
    a form falls back to `box` and **says so in its report**; an
    unrecognised one renders in the loud magenta.
  * `material` — a name only, resolved in `materials.json`.
* `materials.json` holds each material's `colour` (r, g, b, a in 0..1),
  `roughness` and `metalness` — **once**, so the properties are not
  repeated across 95 catalog entries.  `unknown` is the deliberate
  fallback and is loud on purpose: an item the catalog does not define
  must look wrong rather than plausible.
* `groups.json` defines the palette's expandable sections: a list of
  `{name, items}` where each item is an SVG file name from this
  directory.  A furnishing may appear in several groups.  The `All`
  group always shows the whole library and is open by default.

To add your own symbol: drop an SVG here whose viewBox matches the
real-world footprint in inches, add a manifest entry, and list it in
the groups it belongs to.

**Everything in this directory is generated by `_gen_assets.py`** —
including this README, the manifest and `materials.json`.  Edit that
script and re-run it; a hand edit here is overwritten on the next run.
