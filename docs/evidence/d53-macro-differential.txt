-- HOW THE BAD CLAIM HAPPENED, because that is the reusable part ------------

A single run of the probe showed every line matching, and it was written up
as 'identical to main at every line'. On a comparator that flaps roughly half
the time, one matching run is close to a coin landing heads: the reading was
true of that run and says almost nothing about the tree.

This is VACUOUS BY BASIS -- the third shape in the working agreement -- one
layer up from where that rule was first written. P3.8's ratio tests flapped on
machine load, so a green meant 'the runner was quiet'. Here a DIFFERENTIAL
RECEIPT flapped, so a match meant 'this run agreed'. A differential is only as
good as the stability of the field it compares, and the fix is the same one
the suite already applies to timings: repeat the measurement, or compare a
field that does not move.

It was caught by re-running the probe after an unrelated refactor and getting
a DIFFERENT answer on a tree whose behaviour could not have changed -- then
bisecting, reaching an impossible conclusion (a context-menu handler that is
entered ZERO times during the replay), and testing the instrument instead of
believing the bisect.
