# Archived handoff pairs

**A closed pair moves here when its task ticks.** The mailbox one level up shows
what is live; this directory keeps what was decided.

Nothing is edited on the way in — a pair is moved, not rewritten, and the
numbering is never reused. `tools/ref_audit.py` scans this directory like any
other, so a reference into an archived pair keeps resolving.

*Empty until the first task closes. This file exists so the directory does, and
because a directory with no explanation is an invitation to guess.*
