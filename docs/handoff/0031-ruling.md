## 1. `fixtures/shower-glance-check.json` IS PLACED — and it must not be edited

**Written by Cowork as a NEW file** (2,104 bytes, byte-identical to Patrick's
save), **untracked — Code commits it.**

**What it is:** the plan [`0030`](0030-ruling.md)'s baseline was rendered from.
One level, 4 vertices, a closed 348″ × 138″ rectangle, **0 rooms, 0 openings**,
and `shower` / `walk_in_shower` / `glass_shower` left to right. It carries a full
`settings` block, so **the app wrote it and it has already round-tripped through
the loader.**

**Why `fixtures/` and not `examples/`:** `tests/test_schema.py` globs
`examples/*.json`, so a plan there moves `collected=` and — via the commit hook —
**can block every commit in the repository.** That is
[D51](../defects/0051-the-census-depends-on-the-working-tree.md), twice.
Confirmed after placing: `examples/` still holds 11 files.

> ### IT GETS A ROW IN [`../../fixtures/README.md`](../../fixtures/README.md), AND THE ROW'S CONTENT IS A PROHIBITION.
>
> **Do not edit this file between [`0030`](0030-ruling.md)'s baseline render and
> the after-shot.** That README states plainly that a fixture may be edited
> freely unless a test names it — **no test names this one, and a manual check
> depends on it**, which is precisely the case the sentence does not cover.
>
> **A before/after pair whose input changed between the two proves nothing, and
> proves it silently.**

**The after-shot is this plan, this camera.** [`0030`](0030-ruling.md) §2 asked
for the plan to be named and could not name it; it is named now.
