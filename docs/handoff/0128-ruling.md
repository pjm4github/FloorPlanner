# 0128 — ruling: opening stations leave EVERY dimension row — and the intent behind it is now on the record

**Numbering note: authored and dated as `0125`, renumbered `0128` on landing
— see [`0127`](0127-ruling.md)'s own note.**

**Patrick, 2026‑08‑30, answering [`0127`](0127-ruling.md) §1's question:**

> *"Yes drop the doors, opening and windows from the callouts for the PDF. This
> will be the reference that will be sent to the architect who will redraw
> those windows and doors."*

---

## 1. RULED — global, all rows, all opening kinds

**Doors, windows, and every other opening kind leave the dimension stations of
every row and lane** — the bottom X row, the left Y row, and the angled lanes.
Stations are **wall endpoints only**, everywhere. The original template's
*"every opening centerline"* clause is retired — **superseded by its own
author, with the reason quoted above.**

**Openings still DRAW** — symbols and their W/H tags (`3080 = 3'-0" x 6'-8"`)
are untouched. What changes is only which stations the dimension strings
measure between. **The sheet's own footer note should say so:** one line —
*"openings shown for reference; not dimensioned"* — beside the existing
dimension-reference note, so the receiving architect reads the omission as a
decision, not a gap.

## 2. WHY THE INTENT SENTENCE MATTERS MORE THAN THE INSTRUCTION

**The PDF's job is now stated: a reference for an architect who will redraw the
openings.** That is the strongest form of the D82 principle — the sheet
communicates the shell; the openings are somebody else's decision, so
dimensioning them would present as data what is actually a placeholder.

**Recorded because it decides future questions before they are asked:** any
proposal to add per-opening dimensions, jamb offsets, or rough-opening callouts
to this PDF is **refused by default** against this line, until Patrick says the
document's job has changed.

## 3. CONSEQUENCE — the bottom row gets shorter, on purpose

The dense run of small segments in `DIM45.png`'s bottom row (`3'-1"`, `2'-8"`,
`2'-3"`…) was substantially opening centrelines splitting wall runs.
**Expect visibly fewer, longer segments after this lands — that is the feature,
not a regression**, and the telescoping receipt ([`0118`](0118-ruling.md) §2)
must still hold on the reduced station set: row 1 sums to row 2, both axes,
corpus-wide.
